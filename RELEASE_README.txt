ScreenLingo 1.3.0 — Windows x64

完整解压后运行 ScreenLingo.exe，无需 Python，请保留 _internal 文件夹。
右键托盘 → 首选项，填写自己的翻译服务凭据并应用。发行包不含个人密钥。
支持有道、百度、Google、DeepSeek；RapidOCR 本地识别，文字发送给所选翻译服务。
DeepSeek 默认关闭思考。不附带或下载 GLM-OCR 或本地大语言模型。

Ctrl+T 框选翻译；Ctrl+Shift+T 全屏；Esc 清除覆盖；Ctrl+Y 输入翻译。
Ctrl+Y 读取当前输入框，翻译完成后直接全选替换，不自动发送。
等待期间新输入的文字也会被替换；切换窗口则停止粘贴。
输入翻译默认中文到韩文，可在首选项或托盘更换目标语言。
也可选择仅翻译剪贴板，手动复制粘贴。屏幕实时翻译与输入翻译可并行。
固定背景模式：保留第一次取色，文字不变不重绘，减少动态背景闪动。
日文漫画可选竖排（上到下、右到左），建议框选单个气泡或分镜。
背景融合不是 AI 图像修复，复杂纹理仍可能出现色块。

支持 Windows 账户加密保存密钥和登录 Windows 自动启动。
升级前退出旧版，解压到新目录，原用户设置会保留。
移动目录后重新应用自启动，删除前先取消自启动。完全退出使用托盘菜单。
Windows 10 2004+ / Windows 11 x64，Windows 10 尚未实机复测。
游戏推荐无边框模式，输入框需支持 Ctrl+A/C/V，不保证所有游戏兼容。
网络和文本长度会影响耗时，不保证 500ms 内完成。
