ScreenLingo 1.2 Release — Windows 10 2004+ / Windows 11 x64

自动识别在至少 8 个逻辑处理器的电脑上并行运行通用和韩文识别模型。
保持原来的置信度选择规则；固定语言仍只运行对应模型。

解压整个文件夹到固定位置，双击 ScreenLingo.exe，无需安装 Python。
不要只复制 exe，必须保留 _internal 文件夹（包含离线 OCR 模型）。
启动后在系统托盘找到“译”，右键 → 首选项。

推荐：RapidOCR＋有道翻译，填写你自己的应用 ID 和应用密钥（不需要额外 apikey）。
本程序不会附带任何人的密钥。勾选加密保存后，仅当前 Windows 账户可解密。
原文可选自动识别、日文、英文、韩文或中文，目标语言单独设置。
固定原文语言更适合游戏聊天；百度图片接口目前只用于开发测试，不在实时菜单中。

Ctrl+T 框选翻译，Ctrl+Shift+T 全屏，Esc 清除覆盖层。
首选项可设置热键、实时监测、检测间隔、遮罩透明度、代理及开机自启动。
设置分为翻译、识别与显示、快捷键与启动三个标签页，保持传统简洁样式。
覆盖效果默认“背景融合”：按原文边缘背景色不透明擦除，再绘制译文。
适合纯色网页、文档和漫画气泡；不是 AI 图像修复，复杂纹理可能有色块。
游戏或复杂画面可改用“深色遮罩”，相邻遮罩不再叠加变深。
横排译文左对齐；不再压暗整个选区，译文未就绪时保留原文。
点击“应用”保存；关闭首选项仍驻留托盘，完全退出请用托盘菜单“退出”。
勾选自启动后，在下一次登录 Windows 时启动到托盘，不需要管理员权限。
移动程序目录后请重新勾选自启动并应用；删除程序前请先取消自启动并应用。

文字识别在本地完成，识别出的文字发送给所选翻译服务。
自动保存密钥默认关闭；可手动勾选 Windows 账户加密保存。
500ms 不是保证值，网络与文本长度会影响耗时。
CS2、DJMAX 等实际游戏兼容性仍需用户自行验证，建议无边框窗口模式。

可选 GLM-OCR（实验性）：默认不下载、不加载，release 不包含它的权重或 Ollama。
如需使用，在识别与显示页打开 Ollama 官网，安装并运行后点击“下载 GLM-OCR”。
模型下载可能超过 2GB；下载按钮可取消，不需要云端 API Key。完成后检查模型并选择 GLM。
GLM 只连接本机 127.0.0.1:11434；运行需较多内存/显存，不保证实时速度。
本版验证了可选组件流程的离线协议测试，尚未完成 GLM 真机推理测试；优先使用 RapidOCR。
